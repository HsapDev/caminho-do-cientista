Caminho do Cientista 🧪
📝 Descrição
O Caminho do Cientista é uma plataforma de organização de estudos que permite aos usuários catalogar matérias e visualizar um roteiro de aprendizado estruturado. O sistema filtra o conteúdo por disciplina, indicando materiais de apoio necessários e questões estratégicas que validam o conhecimento adquirido.

Este projeto resolve o problema da desorganização nos estudos e a dificuldade de retenção de conteúdo a longo prazo, centralizando o fluxo de aprendizagem de forma lógica e acessível.

🎯 Objetivo
O desenvolvimento deste sistema teve como foco principal consolidar conhecimentos em Backend, aprofundar habilidades em Frontend e explorar a integração de fluxos de automação. O resultado é um produto funcional e objetivo, focado em entregar valor real com um escopo bem definido.

🚀 Funcionalidades
Backend Robusto: Desenvolvido com Spring Boot, utilizando a arquitetura de camadas (Model, DTO, Service e Controller) para garantir organização e escalabilidade.

Gerenciamento de Dados: Integração completa com banco de dados para persistência das matérias e conteúdos.

Interface Dinâmica: Front-end desenvolvido em JavaScript para interação fluida com o usuário.

Automação: Scripts integrados em Python para auxiliar na gestão e processamento de informações do sistema.

🛠 Tecnologias Utilizadas
Linguagens: Java, Python, JavaScript.

Backend: Spring Boot.

Frontend: HTML5, CSS3, JavaScript.

Controle de Versão: Git.
